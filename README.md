Entry for the [Midnight Fridge Roast](https://make.fun/bounty/u-carbon-forge-midnight-fridge-roast-fc5d44a7) bounty on [make.fun](https://make.fun).

`main.ts` (Node, stdlib only) writes one line — a roast of a smart fridge that refuses to open after midnight — to `/output/entry.txt`.

> My fridge locks at midnight like it's guarding state secrets — it's leftover pasta, not the nuclear codes.

Run it with `node main.ts`.
